# CGDI — projeto vigente

Este é o projeto ativo da CGDI. V1 e V2 são as únicas versões com HTML nesta etapa; V3 e V4 estão reservadas para desenvolvimento posterior.

## Estrutura

- `componentes/`: fonte única dos componentes reutilizáveis.
- `projetos/v1/`: fluxo completo da V1.
- `projetos/v2/`: home da V2.
- `projetos/v3/` e `projetos/v4/`: diretórios reservados, sem HTML.
- `projetos/assets/`, `projetos/images/` e ativos específicos de V1/V2: recursos utilizados pelas páginas vigentes.

Use `npm run check` para validar o escopo e os contratos do projeto vigente.
