# Quarentena

Conteúdo preservado fora da arquitetura ativa. Nada desta árvore é publicado
ou consumido por `public/`.

## Classificação

- `a-revisar/`: dados, documentos, páginas, mídia e código com possível valor;
- `duplicatas/`: cópias exatas mantidas até decisão de retenção;
- `legado/`: capturas brutas, backups e versões históricas;
- `inventario/`: registro de hashes, movimentos e decisões.

## Regra de promoção

Um item só pode voltar para `public/` depois de ter origem, atualidade,
licença, dependências, nomes, links, acessibilidade e comportamento responsivo
revalidados. A promoção deve ser registrada no inventário.

Arquivos históricos preservam seus nomes originais. A convenção de nomes
minúsculos, ASCII e `kebab-case` se aplica ao código ativo e a novos itens.
