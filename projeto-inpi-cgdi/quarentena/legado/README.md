# Legado — revisar antes de reutilizar

Esta pasta reúne materiais removidos da arquitetura ativa durante a limpeza do
projeto. Nenhum arquivo daqui é necessário para abrir a página inicial ou as
páginas publicadas da V1, V2 e dos diagnósticos.

## Organização

- `backups/`: cópias intermediárias produzidas durante revisões anteriores;
- `capturas-brutas/`: páginas e recursos salvos do portal original;
- `documentacao/`: mapas, planos e anotações de trabalho;
- `previews/`: páginas isoladas usadas apenas para conferência;
- `recursos-antigos/`: ativos e códigos compartilhados que não são consumidos;
- `versoes-nao-publicadas/`: estruturas reservadas ou ainda não publicadas.

Antes de restaurar qualquer item, verifique se ele ainda é compatível com os
componentes e contratos atuais.
